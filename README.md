# LabGuard Demo Guide
---------------------------
Kalian bisa langsung download file 'labguard_github_ready.zip'
Lalu dimasukkan ke compiler seperti VSCode yang dimana file zipnya sudah di extract
Ada beberapa hal yang harus di download:
1. Via terminal/CMD yang dibuka sebagai administrator
- py -m pip install ultralytics opencv-python
- pip install flask opencv-python ultralytics
2. Setelah kalian sudah membuka folder di VSCode, kalian bisa ketik di terminal 'pip install -r requirements.txt'
Troubleshoot jika tidak mendeteksi command tersebut:
ketik 'ls' di terminal, jika hanya folder yang terlihat sebagai output, ketik 'cd [nama folder] '
Lalu ulangi step 2
3. ketik di terminal 'python backend/app.py'
4. Lalu program harusnya berjalan dan akan mengeluarkan sebuah web 'http://127.0.0.1:5000'

Note: Pada file zip juga ada file readme untuk beberapa hal yang ada di 1 folder tersebut

Submission yang harusnya kami submit ke platform : https://susurimyuun.github.io/LabGuard/
